# 🎬 Netflix Movie Recommendation System

## 📌 Project Overview

This project is a **content-based movie recommendation system** built using Python and Machine Learning.

The system recommends movies similar to a selected movie based on its **genre and overview**.

## 🎯 Objective

The main objective of this project is to build a simple movie recommendation system using:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- TF-IDF Vectorization
- Cosine Similarity

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- GitHub
